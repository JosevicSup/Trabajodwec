# Snake Game in Vue.js (Vite) 🐍

Este es un juego de Snake moderno e interactivo desarrollado en **Vue 3** y **Vite**, desplegado en **Firebase Hosting** y gestionado con un flujo profesional utilizando **Jira, Git/GitHub** y un pipeline de **Jenkins**.

## 🚀 Características Premium (5 Funcionalidades)

1. **Persistencia de Puntuación (High Score)**: Guardado automático en `localStorage`.
2. **Velocidad y Dificultad Dinámica**: Selector inicial y aceleración progresiva de la serpiente.
3. **Power-ups y Obstáculos**: Manzanas doradas, plátanos podridos y paredes dinámicas en el escenario.
4. **Temas Visuales**: Selector de diseños visuales premium (Cyberpunk Neon, Retro Arcade y Pastel Dream).
5. **Efectos de Sonido Retro (Web Audio API)**: Sintetizados dinámicamente en tiempo real (sin dependencias externas) con control de silencio.

## 🛠️ Flujo de Trabajo Integrado

- **Gestión**: Jira (Tablero Scrum / Kanban con Sprint dedicado).
- **Control de Versiones**: Flujo de ramas `feature/SNAK-1-...` creadas desde Jira, unidas a `main` vía Pull Requests.
- **Integración Continua**: Pipeline de Jenkins en cada Push a `main` (Instalación -> Lint -> Tests -> Build -> Deploy).
- **Despliegue**: Firebase Hosting automático.
